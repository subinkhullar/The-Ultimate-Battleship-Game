# ⚓ The Ultimate Battleship Strategy Game by Subin Khullar 😎

A modern, feature-rich naval warfare strategy game inspired by the classic Battleship experience, rebuilt as a powerful Progressive Web App (PWA) using pure HTML, CSS, and JavaScript.

Take command of your fleet, deploy advanced naval weapons, outsmart intelligent AI opponents, unlock achievements, analyse battle statistics, and rise through the ranks to become the ultimate Fleet Admiral.

```text

```

- GitHub Pages
- Netlify
- Azure Static Web Apps
- Vercel

## 🌐 Deploy to GitHub Pages

1. Push repository to GitHub.
2. Open Repository Settings.
3. Navigate to **Pages**.
4. Select the main branch.
5. Save changes.
6. GitHub Pages will generate a public game URL.
